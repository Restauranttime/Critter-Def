# Critter-Def

Drei Handy-Spiele im Browser:

- [Critter Defense](index.html)
- [Sonnensplitter](farm.html): Ein gemütliches Farm- und Dorfspiel mit Jahreszeiten, Tieren, Angeln, einer Höhle voller Abenteuer und einer eigenen Geschichte. Lässt sich über Safari mit „Zum Home-Bildschirm“ als Vollbild-App installieren.
- [Tatort Kleckersdorf](krimi.html): Ein gemütlicher Dorfkrimi im Pixel-Stil. Befrag die Leute im Dorf, sammle Hinweise, halte Widersprüche vor und löse Fälle, mit Dackel Krümel als Spürnase. Lässt sich über Safari mit „Zum Home-Bildschirm“ als Vollbild-App installieren.
